How Entity Confidence is Estimated

By default, spaCy's Named Entity Recognition (NER) does not output probability scores. To estimate a confidence level, we perform a Beam Search (width = 16) over the document.

Rather than evaluating only the single best path, the algorithm keeps track of the top 16 alternative parsing paths.

  • Score Aggregation: We collect all alternative parses containing the specific entity span and label.
  • Normalization: The confidence score represents the sum of the scores of all parses containing that entity, normalized against the total beam score.
  • Speed note: Enabling this causes the model to explore multiple search paths, which increases latency slightly.

spaCy English Models Comparison

en_core_web_sm (Small)

Size: ~12 MB. Optimized for speed and small memory environments. Contains no static word vectors (contextual tensors only). Ideal for basic NER or resource-constrained environments.

en_core_web_md (Medium)

Size: ~40 MB. Balances execution speed and precision. Includes 20k unique static word vectors (300 dimensions). Enables semantic similarity testing (`.similarity()`).

en_core_web_lg (Large)

Size: ~560 MB. Features 685k unique static word vectors (300 dimensions). Delivers the highest precision for NER extraction tasks, but has a larger memory footprint.
